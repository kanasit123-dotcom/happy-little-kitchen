# Happy Little Kitchen

เกมทำอาหารสร้างสรรค์สำหรับเด็ก แยกจากเกมบทเรียนเดิมโดยสมบูรณ์

“ครัวจิ๋วแสนสนุก” มี 9 เมนู: คัพเค้ก พิซซ่า สมูทตี ไข่เจียว ก๋วยเตี๋ยว คุกกี้ ไอศกรีม ขนมปังปิ้ง เค้กวันเกิด
เพื่อน 11 ตัว (แมวน้ำ เต่า กระต่าย + อีก 8 ตัวที่ค่อยๆ มาเล่นด้วยเมื่อป้อนอาหารครบจำนวน) แต่ละวันมีเพื่อน 1 ตัวขออาหาร 1 เมนู ป้อนแล้วเพื่อนมีปฏิกิริยา (ชอบสุดๆ / อร่อย / จาม / อิ่มแปล้)
มีครัวอิสระให้ใส่อะไรก็ได้ลงชาม เลือกเครื่องเอง ได้ "จานลึกลับ" · สมุดผลงานเก็บรูปจานที่แต่งเอง · เสียงประกอบสังเคราะห์ (ฉ่า เดือด ปั่น ติ๊ง)
เด็กหั่น/ตอกไข่บนเขียง เลือกวัตถุดิบ ผสม (ช้อน/ตะกร้อ/ทัพพี/ไม้นวด/มีดทาเนย) ปรุง (เตาอบ/เครื่องปั่น/กระทะ/หม้อ/ตู้แช่แข็ง/เครื่องปิ้ง) ตกแต่ง (วาดครีมด้วยนิ้ว + ท็อปปิ้ง 10 แบบ/เมนู) และเสิร์ฟให้เพื่อนได้ ไม่มีคะแนน ไม่มีคำตอบผิด และไม่มีเวลาจำกัด

## หลักการ

- ใช้ภาพและเสียงเป็นหลัก เด็กเล่นได้โดยไม่ต้องอ่าน
- สลับภาษาไทยและอังกฤษได้ตลอด
- รองรับการแตะและลากบน iPad
- เล่นออฟไลน์ได้หลังเปิดครั้งแรก
- ไม่มีโฆษณา บัญชีผู้ใช้ หรือการสมัครสมาชิก
- เก็บผลงานล่าสุดไว้เฉพาะในเครื่องด้วย `localStorage` key `happy-little-kitchen-v1`

## เปิดในเครื่อง

```powershell
python -m http.server 5174 --bind 127.0.0.1
```

จากนั้นเปิด `http://127.0.0.1:5174/`

## ภาพประกอบ

- ฉากครัวและไอคอนแอปสร้างด้วย OpenAI ImageGen สำหรับโปรเจกต์นี้
- ภาพแมวน้ำ เต่า และกระต่ายนำมาจากคลังภาพของผู้สร้างเกมเดียวกัน
- อาหาร เครื่องครัว วัตถุดิบ เครื่องมือ และท็อปปิ้ง วาดด้วย Gemini จาก prompt ใน `design/PROMPTS-gemini.md` แล้วตัดพื้นหลังด้วย `design/cutout.py` (แผ่นรวมหลายชิ้นใช้ `design/blobs.py` แยกก่อน)
- โฟลเดอร์รูป: `assets/dishes/` `assets/appliances/` `assets/ingredients/` `assets/tools/` `assets/toppings/` — ชื่อไฟล์ = key ในตารางของ `js/app.js`

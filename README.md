# Lilly Playhouse

เกมเล่นอิสระสำหรับลิลลี่ แยกจากเกมบทเรียนเดิมโดยสมบูรณ์

รุ่นแรกคือ “ครัวของลิลลี่” มีคัพเค้ก พิซซ่า และสมูทตี เด็กเลือกวัตถุดิบ คนหรือปั่น ปรุง ตกแต่ง และเสิร์ฟให้เพื่อนได้ ไม่มีคะแนน ไม่มีคำตอบผิด และไม่มีเวลาจำกัด

## หลักการ

- ใช้ภาพและเสียงเป็นหลัก เด็กเล่นได้โดยไม่ต้องอ่าน
- สลับภาษาไทยและอังกฤษได้ตลอด
- รองรับการแตะและลากบน iPad
- เล่นออฟไลน์ได้หลังเปิดครั้งแรก
- ไม่มีโฆษณา บัญชีผู้ใช้ หรือการสมัครสมาชิก
- เก็บผลงานล่าสุดไว้เฉพาะในเครื่องด้วย `localStorage` key `lilly-playhouse-v1`

## เปิดในเครื่อง

```powershell
python -m http.server 5174 --bind 127.0.0.1
```

จากนั้นเปิด `http://127.0.0.1:5174/`

## ภาพประกอบ

- ฉากครัวและไอคอนคัพเค้กสร้างด้วย OpenAI ImageGen สำหรับโปรเจกต์นี้
- ภาพแมวน้ำ เต่า และกระต่ายนำมาจากโปรเจกต์ `game-lilly` ซึ่งเป็นทรัพย์สินของผู้สร้างเกมเดียวกัน
